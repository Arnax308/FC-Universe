# FC Legacy - Development Roadmap

## Phase 0 - Feasibility & Research (Highest Priority)

**Goal:** Prove that the project is technically possible.

Tasks:

* Identify the FC 26 Career Mode save location.
* Reverse engineer or integrate an existing save parser.
* Determine every field that can be extracted.
* Export parsed data into JSON.
* Compare saves across multiple seasons.
* Document unsupported data.

Deliverables:

* Working parser
* Sample JSON output
* Data extraction report
* List of supported/unsupported fields

Project should NOT continue until this phase succeeds.

# Guiding Principles

* Never modify save files.
* Never lose historical data.
* Everything is append-only.
* Every Career Mode is isolated.
* Parser should be replaceable.
* UI must remain independent of parser.
* Backend must remain independent of frontend.
* Optimize for careers spanning 20+ seasons.

---

# Success Criteria

The application should allow a user to play a Career Mode for 15–20 seasons 
and then explore that save as if it were a real football universe.

Every trophy, transfer, award, club, player, manager, and 
competition should have a persistent, searchable history that EA FC itself does not provide.
